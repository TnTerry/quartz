# AGENTS.md

## Build & Dev

```bash
npm ci                     # first time setup (Node >=22, npm >=10.9.2 enforced via .npmrc)
npm run check              # typecheck + prettier check (what CI runs)
npm test                   # run tests (node:test via tsx)
npm run format             # prettier --write
npx quartz build           # build static site to public/
npx quartz build --serve   # build + serve with live reload
```

CI order matters: `npm run check` → `npm test` → `npx quartz build --bundleInfo -d docs`

## Architecture

- `quartz/` — the static site generator framework (cli, components, plugins, utils)
- `content/` — user markdown content (gitignored, built by users who clone Quartz as a template)
- `quartz.config.ts` — plugin configuration (transformers, filters, emitters)
- `quartz.layout.ts` — page layout (components per page type)
- `public/` — build output (gitignored, generated by `npx quartz build`)

## Plugins

Three plugin types registered in `quartz.config.ts` → `quartz/plugins/`:
- **Transformers** — process markdown → HTML (parse, remark/rehype plugins)
- **Filters** — filter out content (e.g., drafts, private pages)
- **Emitters** — emit output files (HTML pages, RSS, sitemap, assets)

Plugins are re-exported via `quartz/plugins/index.ts` barrel file.

## Testing

Tests use Node's built-in test runner (`node:test`). Run them with `npm test` which invokes `tsx --test`.

```bash
npm test                            # all tests
npx tsx --test quartz/util/path.test.ts  # single test file
```

## Tech Stack

- TypeScript strict mode, ESM (`"type": "module"`)
- JSX via Preact (`preact` + `preact-render-to-string`)
- SCSS modules (type `*.scss` → `string` declared in `index.d.ts`)
- Build tooling: `esbuild` for bundling, `lightningcss` for CSS, `sharp` for images

## Style

- Prettier: `printWidth: 100`, `trailingComma: "all"`, `semi: false`, `tabWidth: 2`
- No comments unless essential (code should be self-documenting)
